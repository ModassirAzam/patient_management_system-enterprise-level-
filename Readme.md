Project Overview
This project is a Spring Boot-based microservices healthcare system built with a focus on real-world software architecture practices.
It includes the development of multiple services like Patient Service, Billing Service, Analytics Service, and Authentication Service, using technologies like gRPC, Kafka, Docker, Spring Security, and API Gateway.
It also covers integration testing, OpenAPI documentation, and full deployment on AWS using CloudFormation and LocalStack for local cloud simulations.
Each service is containerized and orchestrated to simulate a production-grade environment.
